# Zhenzhu Releases

This public repository hosts official macOS release downloads and the signed
Sparkle update feed for [Zhenzhu](https://zhenzhu.app).

- Download the latest version from
  [GitHub Releases](https://github.com/minhnd-dev/zhenzhu-releases/releases/latest).
- The signed update feed is published automatically to the `updates` branch.
- Application source code and signing credentials are not stored in this
  repository.

The `updates` branch and release assets are managed by the private release
workflow. Do not edit `appcast.xml` manually.
